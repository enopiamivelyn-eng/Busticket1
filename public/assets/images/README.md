# Images Directory

This folder contains images used in the Salazar Lost and Found System.

## Image Files:
- **logo-SCSIT.png** - SCSIT College logo (displayed above "Salazar Lost and Found")
  - Recommended size: 100x100 pixels or larger
  - Should have transparent background for best results
  - Used in login page and sidebar

## Layout:
The logo displays as:
```
[SCSIT Logo Image]
Salazar Lost and Found
        ^^^^^^^^^^^^^^^ (highlighted in gold/yellow)
```

## Usage:
Place your logo-SCSIT.png file in this directory. The logo will automatically appear:
- Above "Salazar Lost and Found" text on the login page
- At the top of the sidebar on all pages

The text "Salazar Lost and Found" will appear with "Lost and Found" highlighted in gold/yellow color (#fbbf24).
