# Images Directory

This folder contains images used in the Bus Ticketing System.

## Image Files:
- **mylogo.png** - Main application logo (displayed in sidebar)
  - Recommended size: 50x50 pixels or larger
  - Should have transparent background for best results
  - Used throughout the application in all pages

## Usage:
Place your mylogo.png file in this directory. The logo will automatically appear in the sidebar of all pages and on the login screen.
