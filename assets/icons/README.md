# Icons Directory

This folder contains all the icons used in the Bus Ticketing System.

## Icon Files:
- arrowicon.png - Back arrow icon
- arrowpointicon.png - Arrow pointer/direction icon
- busicon.png - Bus icon
- calendar.png - Calendar icon for date selection
- checkgicon.png - Checkmark/success icon
- deleteicon.png - Delete/trash icon
- editicon.png - Edit/pencil icon
- QRicon.png - QR code icon
- searchicon.png - Search/magnifying glass icon
- gcashlog.png - GCash payment logo

## Note:
- The main logo (mylogo.png) is located in assets/images/ folder
